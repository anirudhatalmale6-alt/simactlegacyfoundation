Donation link setup

Paste the Clover Payment Link below. This page checks it, shows you exactly what the Donate button will do, and writes out the one line to put in the site’s config file. Nothing here is saved to a server — it is a helper, not an admin panel.

1. Get the link from Clover

  1. Sign in to the Clover dashboard.
  2. Open Ecommerce, then Payment links.
  3. Choose Create new, then URL.
  4. Give it an internal name, for example Website donation.
  5. Choose Variable so the donor types their own amount. (Preset fixes a single amount — not what a donation page wants.)
  6. Save it, then Copy URL.

If Payment links is not in the menu, Ecommerce is probably not switched on for the account — that is a call to Clover support, not something the website can fix. Clover online payments are available in the United States and Canada.

2. Paste it here

This is exactly what a visitor will see and do: Donate Now

3. Put it in the site

Open assets/site-config.js and replace the DONATE_URL line with the line below. That is the only edit — every Donate button on the site reads from it. 

  DONATE_URL: "",

4. Before going live

  1. Reload the site and check the Donate button in the header, the hero, the donation section and the footer.
  2. Click one. It must open Clover in a new tab, showing the foundation’s name.
  3. Make one real donation of a small amount and confirm it appears in Clover’s Transactions. A link that looks right and does not settle is the failure worth catching before launch, not after.
  4. Refund that test donation from the Clover dashboard.

Reusing this template for another organisation: copy the site folder, replace assets/logo.jpg, and edit assets/site-config.js — name, contact details, figures and this donation link. No other file is touched, and assets/donate.js is never edited.
